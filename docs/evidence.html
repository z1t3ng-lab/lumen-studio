02 / shipped client code

Boundaries we can point to.

  • Named editing parameters

    The Light-panel template creates an Exposure control with the identifier Exposure2012. Components dispatch parameter updates into an editing store.

  • A graphics presentation layer

    An image-view component initializes WebGL or WebGL2, a shader program, and image texture and vertex buffers. This is present code; we did not trace that function executing.

  • A rendering bridge

    A preview path requests default pixels, wraps the returned bytes as ImageData, draws through Canvas, and applies crop orientation.

  • Develop settings as data

    The captured edit route handles XMP develop settings, crop dimensions, orientation, masks, and filters. It does not reveal every processing stage.

04 / limits and provenance

What this evidence does—and does not—establish.

The final experiment is complete for its declared screenshots, accessibility, page-error, and worker captures. It did not request network capture. Static analysis is partial: the parser recovered errors in one client bundle. Source maps were not fetched, and capture origin restrictions excluded other scripts and resources.

RAW decoding, internal color spaces, tone-mapping equations, AI processing, authenticated persistence, export fidelity, and desktop/web equivalence remain unresolved. The desktop application was not installed on this Mac.
